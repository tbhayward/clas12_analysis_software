# CFF notation in the decomposition CSVs

| label | object | what it is | 
|---|---|---|---|
| `F11` | GTMD $F_{1,1}$, $k_\perp$-integrated | unpolarized quarks in an unpolarized nucleon; TMD limit $f_1$, $k_\perp$ integral gives $H$, $E$  |
| `G11` | GTMD $G_{1,1}$, $k_\perp^2$ moment | spin–orbit correlation; no TMD limit, moment at $\Delta=0$ gives $C_q$ |
| `G14` | GTMD $G_{1,4}$, $k_\perp$-integrated | quark helicity; TMD limit $g_{1L}$, $k_\perp$ integral gives $\tilde H$, $\tilde E$  |
| `F14` | GTMD $F_{1,4}$, $k_\perp^2$ moment | quark orbital angular momentum; no TMD limit, moment gives $-L_q$ |
| `F12` | GTMD $F_{1,2}$, $k_\perp^2$ moment | nucleon helicity flip; TMD limit is the Sivers function $f_{1T}^\perp$, moment gives the Qiu–Sterman $T_F(x,x)$  |
| `G12` | GTMD $G_{1,2}$, $k_\perp^2$ moment | nucleon helicity flip; TMD limit is the worm gear $g_{1T}$, moment gives $2g_{1T}^{(1)}$  |
| `HT` | GPD $H_T$ | chiral-odd transversity GPD; forward limit $h_1$  |
| `EbarT` | GPD $\bar E_T = E_T + 2\tilde H_T$ | chiral-odd; first moment is the tensor anomalous magnetic moment $\kappa_T$ |
| `HtL` | GPD $\tilde H$ in the longitudinal amplitude | quark helicity; forward limit $\Delta q$  |
| `EtL_np` | non-pole part of GPD $\tilde E$ | helicity-flip partner of $\tilde H$ |
| `EtL_pole` | pion-pole part of $\tilde E$ | $t$-channel pion exchange, $\pi^\pm$ only; in the longitudinal and transverse amplitudes |
| `calE` | $\mathcal E$: GPD $E$ with the $F_{1,1}$ kernel |
| `calEt` | $\tilde{\mathcal E}$: non-pole $\tilde E$ with the $G_{1,4}$ kernel |
